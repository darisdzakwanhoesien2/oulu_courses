# Artificial Intelligent Exercises and Projects

## Overview
This folder contains a collection of exercises, notebooks, and scripts related to fundamental and advanced topics in artificial intelligence. The materials cover classical search algorithms, constraint satisfaction problems, reinforcement learning, and machine learning techniques.

## Contents
- `ai.ipynb`: Exercises on classical AI search algorithms including Depth-First Search (DFS), Breadth-First Search (BFS), Uniform Cost Search (UCS), Greedy Best-First Search, and A* Search. Includes graph visualizations and tie-breaking strategies. Also covers Traveling Salesman Problem (TSP) hill climbing, constraint satisfaction problems (cryptarithms), arc consistency (AC-3), and value iteration for Markov Decision Processes (MDP).
- `exercise_3.py`: Python script related to AI exercises (not detailed here).
- `exercise_4.ipynb`: Perceptron algorithm for multi-class classification with weight updates, visualization of data points, and prediction on new inputs.
- `exercise_4.py`: Python script related to exercise 4 (not detailed here).
- `exercise_5/`: Folder containing notebooks and scripts for MDPs, policy evaluation, and policy improvement.
  - `exercise5.ipynb`: Markov Decision Process exercises including state utilities computation and policy improvement.
  - `task.ipynb` and `task copy.ipynb`: Additional notebooks related to exercise 5.
- `exercise_6/`: Folder containing reinforcement learning exercises.
  - `q6.ipynb`: Temporal Difference (TD) learning, Q-learning, and visualization of learning processes.
  - `q6_final.py`: Python script related to exercise 6.
  - `test.ipynb`: Additional notebook for testing or exercises.
- `final_code/`: Contains final versions of AI exercises and projects, including implementations of search algorithms, Bayesian networks, classification methods, and Pacman AI projects.
- `ai_json/`: JSON files related to AI exercises.
- `supplementary/`: Additional resources and notebooks, including Bayesian networks.

## Topics Covered
- Classical search algorithms and graph/tree search strategies.
- Constraint satisfaction problems and backtracking search.
- Reinforcement learning: Temporal Difference learning, Q-learning, and policy evaluation.
- Machine learning: Perceptron algorithm for classification.
- Markov Decision Processes and policy improvement.
- Visualization of AI algorithms and learning processes.
- Practical AI projects including Pacman AI implementations.

## Usage
- Ensure Python 3.x is installed with necessary packages such as numpy, matplotlib, pandas, networkx.
- Open and run the Jupyter notebooks to explore exercises and visualize results.
- Review Python scripts for detailed implementations of algorithms.
- Use the final_code folder for complete project implementations.
